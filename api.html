Configuration Réseau

Pour interagir avec la blockchain Nexus Core L1, vous devez configurer votre client Web3 (Ethers.js, Web3.js ou appels HTTP natifs) avec les paramètres industriels suivants :

URL du Endpoint RPC

https://rpc.agi-nexus-core.click

Chain ID (BFA)

226 (Mainnet)

Symbole Devise

AGI (₳)

Explorateur de Blocs

explorer.agi-nexus-core.click

Authentification & Limites

Le nœud RPC public est ouvert et sans clé d'API requise pour faciliter l'intégration industrielle de l'écosystème. Cependant, un pare-feu matériel Atlas & Duc applique un Rate Limiting strict pour prévenir les attaques DDoS.

  • Limite par IP : 100 requêtes / seconde
  • Taille max du payload : 2 MB

POST nexus_blockNumber

Retourne le numéro du bloc le plus récent synchronisé sur le réseau L1.

Exemple cURL 
curl -X POST https://rpc.agi-nexus-core.click \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"nexus_blockNumber","params":[],"id":1}'

Réponse JSON (Succès)

{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x12b4" // Bloc #4788
}

POST nexus_getBalance

Retourne le solde d'une adresse donnée. Le montant est retourné en microA (1 AGI = 1,000,000 microA).

Paramètres (Array)

  1. "DATA" : 20 Bytes - L'adresse à interroger.
  2. "QUANTITY|TAG" : (Optionnel) "latest", "earliest" ou numéro de bloc.
Exemple cURL 
curl -X POST https://rpc.agi-nexus-core.click \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"nexus_getBalance","params":["0x89205A3A3b2A69De6Dbf7f01ED13B2108B2c43e7", "latest"],"id":1}'

POST nexus_sendRawTransaction

Soumet une transaction pré-signée (chiffrée) au réseau pour validation L1 et minage.

Les données doivent être signées avec une clé privée ECDSA valide. L'API RPC du nœud L1 ne signe jamais les transactions pour vous des raisons de sécurité industrielle.

Exemple JavaScript (Fetch) 
const signedTx = "0xf86c098504a817c80082520894353535...";

const response = await fetch("https://rpc.agi-nexus-core.click", {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    jsonrpc: "2.0",
    method: "nexus_sendRawTransaction",
    params: [signedTx],
    id: 1
  })
});

const data = await response.json();
console.log("Tx Hash:", data.result);
