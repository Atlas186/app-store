REST API (Exchange & Données)

Endpoints publics (GET) optimisés pour l'intégration CoinMarketCap, CoinGecko et les plateformes DEX.

GET

/api/exchange/ticker

Fournit les volumes d'échange on-chain (DEX AGI) sur les dernières 24 heures et le prix en temps réel.

Requête 
curl -X GET https://rpc.agi-nexus-core.click/api/exchange/ticker
Réponse (JSON)
{
  "AGCOIN_XOF": {
    "base_id": "AGCOIN",
    "quote_id": "XOF",
    "last_price": "1.00",
    "base_volume": "1050.00",
    "quote_volume": "1050.00",
    "isFrozen": "0"
  }
}
GET

/api/total-supply

Retourne la supply totale d'AG-COIN en format texte brut.

curl https://rpc.agi-nexus-core.click/api/total-supply
>> 100000000000
GET

/api/exchange/assets

Spécifications techniques de l'actif pour les plateformes d'échange.

curl https://rpc.agi-nexus-core.click/api/exchange/assets
>> {"AGCOIN": {"min_withdraw": "1000.00"...}}

Méthodes JSON-RPC (Web3)

Opérations on-chain standards. Requiert un Header Content-Type: application/json.

POST

nexus_chainId

Retourne l'identifiant cryptographique de la chaîne actuelle.

Payload / Réponse
// Request
{
  "jsonrpc": "2.0",
  "method": "nexus_chainId",
  "params": [],
  "id": 1
}
// Response
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x2334" // Décimal: 9012
}
POST

nexus_getBalance

Retourne le solde d'une adresse. La réponse inclut le montant en microA (décimales: 6), le format lisible, et l'équivalence stricte en XOF.

Exemple Complet 
// Request
{
  "jsonrpc": "2.0",
  "method": "nexus_getBalance",
  "params": ["0x89205A..."],
  "id": 2
}
// Response
{
  "jsonrpc": "2.0",
  "id": 2,
  "result": {
    "address": "0x89205A...",
    "microA": "5000000000",
    "formatted": "5000.000000 ₳",
    "parityXOF": "5000.000000 FCFA"
  }
}
POST

nexus_getTransactionCount

Obtient le Nonce actuel d'une adresse, requis pour l'envoi de transactions (prévention du double-spending).

Params: ["0xVotreAdresse"]
Result: "0x5" // Le prochain Nonce à utiliser est 5

Smart Contracts L1 (NCRC20)

Interactions avec la Machine Virtuelle Nexus (VM) et exécution des contrats.

POST

nexus_getContractState

Retourne l'état actuel de la mémoire d'un contrat déployé sur le L1.

Requête & Réponse 
{
  "jsonrpc": "2.0",
  "method": "nexus_getContractState",
  "params": ["AGICa1b2c3d4..."],
  "id": 3
}
{
  "jsonrpc": "2.0",
  "id": 3,
  "result": {
    "name": "Atlas Token",
    "balances": {
       "0x123...": 1500
    }
  }
}
POST

nexus_sendRawTransaction

Permet d'envoyer des fonds, de déployer un contrat (type: 'deploy_contract') ou d'appeler un contrat (type: 'call_contract').

Les transactions sont signées côté client. Le nœud RPC n'accepte que les transactions formatées avec une signature valide ou soumises via la mempool sécurisée d'Atlas & Duc.

Exemple : Appel de contrat intelligent (JS) 
const rawTx = {
  type: 'call_contract',
  from: '0xMonAdresse',
  to: 'AGIC_AdresseDuContrat',
  action: { method: 'mint', params: [1000] },
  nonce: 5,
  feeMicro: 5000 // 0.005 AGI
};
// Envoyer ce JSON (après l'avoir stringifié) via nexus_sendRawTransaction

Flux Temps Réel (WSS & P2P)

Écoutez le réseau Nexus Core L1 en temps réel via le port 6001.

ws://p2p.agi-nexus-core.click:6001 WSS P2P

Le protocole P2P d'Atlas & Duc émet les événements suivants pour les nœuds observateurs :

  • NEW_BLOCK : Diffusé toutes les 2 secondes par les Validateurs PoA.
  • NEW_TRANSACTION : Diffusé lorsqu'une transaction entre dans la Mempool.

Exceptions & Codes d'Erreur

Standard JSON-RPC 2.0 avec spécificités L1 Nexus.

Code Message Description technique
-32602 Invalid parameters Paramètre manquant (ex: address manquante lors d'un getBalance).
-32000 Fonds insuffisants / Nonce Transaction rejetée : solde insuffisant ou désynchronisation du Nonce.
-32005 Mempool full Capacité maximale de la mempool (5000) atteinte. Réesayez plus tard.
429 (HTTP) Rate Limit Exceeded Système anti-DDoS Atlas & Duc Shield™. Passez au compte B2B.
