0. Comment Connecter Votre Application à Nexus Core L1

POST / • Content-Type: application/json

Le serveur RPC de Nexus Core L1 (CHAIN_ID = 9012, port HTTP par défaut 9545, exposé publiquement sur https://rpc.agi-nexus-core.click) expose une API hybride : des méthodes JSON-RPC 2.0 natives (nexus_*), une compatibilité partielle en lecture JSON-RPC Ethereum (eth_*, net_version, web3_clientVersion), des endpoints HTTP GET RESTful (/api/total-supply, /api/price, /api/transactions, /api/exchange/*, /api/holders), ainsi qu'une synchronisation pair-à-pair via P2PServer et des notifications push Firebase Cloud Messaging (FCM) lorsque la transaction est forgée dans un bloc.

ÉTAPE 1 — Lire l'État & le Nonce

Appelez nexus_getBalance et nexus_getTransactionCount en POST JSON-RPC 2.0. Les soldes natifs sont stockés en BigInt en microA (1 ₳ = 1 000 000 microA, 6 décimales, parité 1 ₳ = 1 XOF).

ÉTAPE 2 — Hasher & Signer (secp256k1)

Construisez txData (type, from, to, amountMicro, feeMicro, nonce, publicKey), calculez hash = Base58(SHA-256(JSON.stringify(txData))), puis signez SHA-256(hash) en DER hex avec la clé privée secp256k1.

ÉTAPE 3 — Diffuser & Suivre le Bloc

Envoyez la transaction signée via nexus_sendRawTransaction. Le nœud met à jour la mempool, ajuste les soldes/nonces en mémoire, diffuse sur le réseau P2P et forge un bloc toutes les 2 000 ms (BLOCK_TIME_MS).

Règles critiques d'adressage & d'encodage : Les adresses de comptes dérivées d'une clé publique secp256k1 commencent par ADC et sont tronquées/complétées sur 44 caractères en Base58 (123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz). Les adresses de smart contracts générées lors du déploiement commencent par ADCC suivi de generateBase58Id(tx.hash). 
import crypto from 'crypto';
import EC from 'elliptic';

const RPC_URL = 'https://rpc.agi-nexus-core.click';
const CHAIN_ID = 9012;
const DECIMALS = 6;
const ONE_A_IN_MICRO = 1_000_000n;
const BASE58_ALPHABET = '123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz';
const ec = new EC.ec('secp256k1');

function encodeBase58(buffer) {
  if (!buffer || buffer.length === 0) return '';
  let digits = [0];
  for (let i = 0; i < buffer.length; i++) {
    for (let j = 0; j < digits.length; j++) digits[j] <<= 8;
    digits[0] += buffer[i];
    let carry = 0;
    for (let j = 0; j < digits.length; j++) {
      digits[j] += carry;
      carry = (digits[j] / 58) | 0;
      digits[j] %= 58;
    }
    while (carry) {
      digits.push(carry % 58);
      carry = (carry / 58) | 0;
    }
  }
  for (let i = 0; i < buffer.length - 1 && buffer[i] === 0; i++) digits.push(0);
  return digits.reverse().map(d => BASE58_ALPHABET[d]).join('');
}

function deriveNexusAddress(publicKeyHex) {
  const pubBuf = Buffer.from(publicKeyHex, 'hex');
  const h1 = crypto.createHash('sha256').update(pubBuf).digest();
  const h2 = crypto.createHash('sha256').update(h1).digest();
  let res = 'ADC' + encodeBase58(h2);
  while (res.length < 44) res += BASE58_ALPHABET[(res.length * 31) % 58];
  return res.substring(0, 44);
}

async function rpcCall(method, params = [], id = 1) {
  const res = await fetch(RPC_URL, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ jsonrpc: '2.0', method, params, id })
  });
  const json = await res.json();
  if (json.error) throw new Error(`RPC Error ${json.error.code}: ${json.error.message}`);
  return json.result;
}

Limite body : 1 Mo • Chain ID : 9012

Toutes les méthodes nexus_* sont exposées en POST sur la racine du serveur HTTP (/). Elles retournent une enveloppe JSON-RPC 2.0 standard ({"jsonrpc":"2.0","result":...,"id":...} ou {"jsonrpc":"2.0","error":{"code":...,"message":...},"id":...}).

2. Construction, Hachage & Signature de Transaction (nexus_sendRawTransaction)

Obligatoire pour toute mutation

Le nœud vérifie rigoureusement chaque transaction via isValidTransaction(tx) avant de l'accepter dans nexus_sendRawTransaction. Voici les règles exactes à respecter côté partenaire :

  • Champs requis : from, hash, amountMicro (non null/undefined), signature et publicKey.
  • Anti-usurpation d'adresse : tx.from doit être strictement égal à deriveNexusAddress(tx.publicKey) (double SHA-256 de la clé publique hexadécimale encodé en Base58 avec préfixe ADC sur 44 caractères).
  • Provision suffisante : BigInt(ledger.getBalance(tx.from)) doit être supérieure ou égale à BigInt(tx.amountMicro) + BigInt(tx.feeMicro || 0).
  • Nonce séquentiel : tx.nonce doit correspondre exactement à ledger.getNonce(tx.from).
  • Hash & Signature ECDSA : txData = { type: tx.type || 'transfer', from: tx.from, to: tx.to, amountMicro: tx.amountMicro, feeMicro: tx.feeMicro || 0, nonce: tx.nonce, publicKey: tx.publicKey }. Le champ tx.hash doit valoir encodeBase58(SHA256(JSON.stringify(txData))), et tx.signature doit valider ec.keyFromPublic(tx.publicKey, 'hex').verify(SHA256(tx.hash), tx.signature).
Effet immédiat sur l'état : Lorsqu'une transaction transfer est acceptée par nexus_sendRawTransaction, elle est ajoutée à mempool avec status: 'pending', le solde de tx.from est débité de amount + fee, le solde de tx.to est crédité de amount, le nonce de tx.from est incrémenté de +1, et la transaction est diffusée aux pairs P2P (NEW_TRANSACTION). 
import crypto from 'crypto';
import EC from 'elliptic';

const ec = new EC.ec('secp256k1');
const BASE58_ALPHABET = '123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz';

function encodeBase58(buf) {
  let digits = [0];
  for (let i = 0; i < buf.length; i++) {
    for (let j = 0; j < digits.length; j++) digits[j] <<= 8;
    digits[0] += buf[i];
    let carry = 0;
    for (let j = 0; j < digits.length; j++) {
      digits[j] += carry;
      carry = (digits[j] / 58) | 0;
      digits[j] %= 58;
    }
    while (carry) { digits.push(carry % 58); carry = (carry / 58) | 0; }
  }
  for (let i = 0; i < buf.length - 1 && buf[i] === 0; i++) digits.push(0);
  return digits.reverse().map(d => BASE58_ALPHABET[d]).join('');
}

function deriveAddress(pubKeyHex) {
  const h1 = crypto.createHash('sha256').update(Buffer.from(pubKeyHex, 'hex')).digest();
  const h2 = crypto.createHash('sha256').update(h1).digest();
  let res = 'ADC' + encodeBase58(h2);
  while (res.length < 44) res += BASE58_ALPHABET[(res.length * 31) % 58];
  return res.substring(0, 44);
}

export async function sendNexusTransfer({ privateKeyHex, toAddress, amountA, feeMicro = 0, nonce, rpcUrl = 'https://rpc.agi-nexus-core.click' }) {
  const key = ec.keyFromPrivate(privateKeyHex.replace(/^0x/i, ''), 'hex');
  const publicKey = key.getPublic(true, 'hex');
  const from = deriveAddress(publicKey);
  const amountMicro = (BigInt(Math.round(Number(amountA) * 1_000_000))).toString();

  const txData = {
    type: 'transfer',
    from,
    to: toAddress,
    amountMicro,
    feeMicro,
    nonce: Number(nonce),
    publicKey
  };

  const hash = encodeBase58(crypto.createHash('sha256').update(JSON.stringify(txData)).digest());
  const msgHash = crypto.createHash('sha256').update(hash).digest();
  const signature = key.sign(msgHash).toDER('hex');

  const signedTx = { ...txData, hash, signature };

  const res = await fetch(rpcUrl, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ jsonrpc: '2.0', method: 'nexus_sendRawTransaction', params: [signedTx], id: Date.now() })
  });
  return await res.json();
}

3. Smart Contracts (deploy_contract & call_contract) et Cloud Mining

Adresse contrat : ADCC + Base58(hash)

Lors de la forge d'un bloc (forgeBlock()), le validateur exécute les transactions contractuelles en JavaScript via la fonction execute(state, action, caller) à l'intérieur d'un isolat isolated-vm (limite mémoire 128 MB, timeout 50 ms) avec repli automatique sur vm si isolated-vm n'est pas installé :

  • Déploiement (type: "deploy_contract") : calcule contractAddress = "ADCC" + generateBase58Id(tx.hash), exécute execute({}, tx.action || { type: 'init' }, tx.from), puis enregistre le code et l'état initial. Si l'état retourné est nul/invalide, la transaction passe en status: 'failed'.
  • Appel (type: "call_contract") : récupère le code et l'état associés à tx.to, exécute execute(state, tx.action, tx.from) et sauvegarde le nouvel état en cas de succès.
  • Notifications FCM : pour chaque transaction marquée status: 'success' lors de la forge du bloc, dispatchL1Notification(tx) vérifie users/{address}/fcm_token dans Firebase Realtime Database et envoie une notification push (dépôt, retrait, migration ou cloud_mining_reward).
  • Cloud Mining : toutes les 60 secondes, CloudMiningManager.processPayouts() inspecte cloud_mining_contracts dans Firebase RTDB ; lorsqu'un cycle (cycle_hours, défaut 24h) est écoulé, il injecte un paiement cloud_mining_reward depuis le compte de trésorerie vers user_address et met à jour last_payout et total_earned.
// Contrat JS devant exposer execute(state, action, caller)
const contractCode = `
function execute(state, action, caller) {

    state.lastCaller = caller;
  }
  return state;
}
`;

5. Méthodes RPC Compatibles eth_* & web3_clientVersion

eth_sendRawTransaction désactivé

Le serveur RPC répond également aux méthodes standards de consultation de type EVM afin de simplifier l'intégration d'outils de supervision ou d'audit :

  • eth_chainId ("0x2334"), net_version ("9012"), eth_blockNumber (index du dernier bloc en hexadécimal).
  • eth_getBalance : multiplie le solde interne en microA par 1_000_000_000_000n (1012) afin d'exposer une valeur compatible 18 décimales en hexadécimal (0x...).
  • eth_getTransactionCount, eth_gasPrice ("0x3b9aca00"), eth_estimateGas ("0x5208"), eth_maxPriorityFeePerGas, eth_feeHistory, eth_getBlockByNumber, eth_getCode ("0x"), eth_call ("0x") et web3_clientVersion ("NexusCore-AtlasDuc/v1.0.0").
  • Restriction d'écriture : eth_sendRawTransaction est volontairement désactivée et retourne l'erreur -32000 ; toutes les transactions signées doivent utiliser nexus_sendRawTransaction.

6. Codes d'Erreur JSON-RPC, Limites & Bonnes Pratiques Partenaires

JSON-RPC 2.0
-32601 • Méthode introuvable

Vérifiez l'orthographe exacte de la méthode (ex. nexus_getBalance, nexus_sendRawTransaction).

-32602 • Paramètre manquant

Vérifiez que params contient bien les arguments attendus (ex. ["ADC..."] ou [rawTx]).

-32000 • Nonce invalide / Signature / Fonds

Re-synchronisez le nonce via nexus_getTransactionCount, vérifiez deriveNexusAddress(publicKey) === from, la signature ECDSA et le solde (amountMicro + feeMicro).

-32005 • Mempool saturé

La mempool a atteint MAX_MEMPOOL_SIZE (50 000 tx) : patientez avant de réémettre la transaction.

Checklist de Mise en Production Partenaire
• Toujours convertir les montants ₳ en BigInt de microA (amountA * 1_000_000).
• Sérialiser txData avec les clés exactes avant calcul du hash Base58.
• Maintenir une file séquentielle par adresse ADC... pour éviter les conflits de nonce.
• Vérifier l'inclusion dans un bloc (nexus_getBlockByNumber ou /api/transactions) pour la confirmation définitive.
