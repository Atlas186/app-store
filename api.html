Référence des Méthodes (JSON-RPC)

Format standard Web3. Les appels requièrent "jsonrpc": "2.0".

POST

nexus_blockNumber

Retourne le numéro hexadécimal du bloc le plus récent synchronisé.

Requête (cURL) 
curl -X POST https://rpc.agi-nexus-core.click \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"nexus_blockNumber","params":[],"id":1}'
Réponse
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x12b4" // Décimal: 4788
}
POST

nexus_getBalance

Retourne le solde d'une adresse en microA (1 ₳ = 1,000,000 microA).

Requête JSON-RPC 
{
  "jsonrpc": "2.0",
  "method": "nexus_getBalance",
  "params": [
    "0x89205A3A3b2A69De6Dbf7f01ED13B2108B2c43e7",
    "latest"
  ],
  "id": 1
}
POST

nexus_estimateGas

Exécute une transaction simulée pour estimer le coût en gaz.

Requête 
{
  "jsonrpc": "2.0",
  "method": "nexus_estimateGas",
  "params": [{
    "from": "0x...",
    "to": "0x...",
    "value": "0xf4240" // 1 AGI
  }],
  "id": 1
}
POST

nexus_sendRawTransaction

Soumet une transaction pré-signée (ECDSA secp256k1) au réseau L1.

Le nœud RPC ne stocke pas de clés privées et refuse les requêtes non signées.

Requête (Web3.js) 
const tx = {
  to: '0xDestination...',
  value: web3.utils.toWei('1', 'ether'), // 1 AGI
  gas: 21000
};
const signedTx = await web3.eth.accounts.signTransaction(tx, privateKey);
web3.eth.sendSignedTransaction(signedTx.rawTransaction)
  .on('receipt', console.log);
POST

nexus_getTransactionReceipt

Retourne le reçu d'une transaction via son hash. (Succès : `status: "0x1"`).

Requête JSON-RPC 
{
  "jsonrpc": "2.0",
  "method": "nexus_getTransactionReceipt",
  "params": ["0x0b8a36...a2c1"],
  "id": 1
}

Flux Temps Réel (WSS)

Écoutez le réseau Nexus Core L1 en temps réel.

wss://ws.agi-nexus-core.click
Souscription aux blocs (newHeads) 
{
  "id": 1,
  "jsonrpc": "2.0",
  "method": "nexus_subscribe",
  "params": ["newHeads"]
}

Codes d'Erreur Standardisés

Gestion des exceptions et dépannage technique.

Code Message Description
-32700 Parse error JSON invalide. Vérifiez la syntaxe (virgules, guillemets).
-32600 Invalid Request Objet JSON invalide. jsonrpc: "2.0" manquant.
-32601 Method not found La méthode invoquée n'est pas supportée par l'API L1.
-32000 Execution error Erreur réseau (ex: fonds insuffisants, nonce trop bas). Lisez data.
429 (HTTP) Too Many Requests Rate Limit dépassé. Ralentissez ou passez au Forfait B2B.
